## 🚀 How to Use

### Basic Usage

```tsx
import InteractiveRoom, { Interactable } from '@/components/InteractiveRoom'

const interactables: Interactable[] = [
  {
    id: 'object1',
    x: 50,        // 50% from left (center)
    y: 30,        // 30% from top
    label: 'Inspect Object',
    size: 80,     // optional, default 60px
    action: () => {
      alert('You found something!')
    }
  }
]

export default function MyRoom() {
  return (
    <InteractiveRoom
      backgroundImage="/rooms/my-room.jpg"
      backgroundAlt="My room description"
      roomTitle="MY ROOM"
      statusText="STATUS: EXPLORING"
      interactables={interactables}
    />
  )
}
```

## 📐 Coordinate System

The `x` and `y` values use **percentages** (0-100) for responsive positioning:

```
0% ←───────────── x ──────────────→ 100%
0%  ┌────────────────────────────┐  
↑   │                            │
│   │         (50, 50)           │
y   │       Center Point         │
│   │                            │
↓   │                            │
100%└────────────────────────────┘
```

**Examples:**
- Top-left corner: `x: 10, y: 10`
- Center: `x: 50, y: 50`
- Bottom-right: `x: 90, y: 90`

## 🎨 Customization

### Change Cursor Icon
Edit the cursor in `InteractiveRoom.tsx`:
```tsx
cursor: isHovered ? 'url("data:image/svg+xml;utf8,<svg...>👁️</text></svg>") 16 16, pointer' : 'default'
```

Replace `👁️` with any emoji or SVG.

### Adjust Visual Effects
Modify opacity and blur values:
```tsx
// Vignette strength
<div className="absolute inset-0 bg-gradient-to-t from-black/70" />
                                                          // ^^^ adjust

// Scanline intensity
className="absolute inset-0 pointer-events-none opacity-[0.03]"
                                                      // ^^^^^^ adjust
```

## 🐛 Troubleshooting

### TypeScript Errors
Run build to auto-configure:
```powershell
npm run build
```

Next.js will automatically configure TypeScript on first build.

### Images Not Loading
1. Verify image path: `public/rooms/your-image.jpg`
2. Check Next.js dev server is running
3. Try absolute path: `/rooms/your-image.jpg`

### Interactables Not Clickable
1. Check `z-index` values
2. Verify `pointerEvents` is set correctly
3. Adjust hitbox `size` property
